# Frozen macOS reference (original Electron app)

This folder is the original Electron + PixiJS version of the project, moved here
unchanged so it can still be run on a Mac to compare behaviour
(`npm install && npm start` inside this folder). It is not built, tested or
shipped by this repository, and no Windows code depends on it.

Known problems are listed in `docs/AUDIT.md` at the repository root; they are
deliberately left as they were.
