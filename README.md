# Погода на рабочем столе — этап 0 (снег)

Десктоп-приложение рисует погодные эффекты поверх рабочего стола. Реализация по ТЗ
«Приложение „Погода на рабочем столе“ (Новый год на десктопе)».

## Стек

Electron + TypeScript + PixiJS (вариант B из ТЗ). Выбор: Rust/Tauri (вариант A)
требует установки тулчейна и медленной первой сборки, а для прототипа этапа 0 нужен
быстрый цикл правок. Архитектура — как в ТЗ: ядро (оверлеи, трей, настройки,
жизненный цикл эффектов) + плагины эффектов, поэтому переезд на Tauri позже
затрагивает только оболочку, но не код эффектов.

## Что уже работает (этап 0 + часть этапа 1)

- Прозрачный оверлей на весь экран на **каждом** мониторе, всегда сверху,
  клики и фокус проходят насквозь (`setIgnoreMouseEvents(true, { forward: true })`).
- Эффект «Снег» на GPU (PixiJS): 3 слоя параллакса, ветер, покачивание,
  настраиваемый цвет, размер и густота; 30 FPS, лимит частиц зависит от площади экрана.
- Трей в строке меню: выбор эффекта, пауза, настройки, выход.
- Окно настроек **генерируется из `manifest.json`** — новый эффект не требует
  отдельного экрана настроек.
- **Этап 2:** нативный трекер окон (`scripts/windowtracker.swift`, `CGWindowListCopyWindowInfo`,
  20 Гц, JSON-строки в stdout) → карта высот на верхнюю грань каждого окна и на нижнюю
  кромку экрана (Dock), сглаженная заливка сугроба, стряхивание в частицы при сдвиге
  окна больше 6 px, пункт трея «Убрать снег».
- Без разрешения **Screen Recording** macOS отдаёт только окна своего процесса, поэтому
  сугробы появляются лишь у нижней кромки экрана. Пункт трея «Доступ к окнам…» вызывает
  системный запрос и открывает нужную панель настроек; после выдачи доступа нужен
  перезапуск приложения.
- Хранение настроек в JSON (`~/Library/Application Support/Снег на десктопе/settings.json`).
- Пауза при блокировке экрана и сне (PowerMonitor).
- Пересоздание оверлеев при подключении/отключении монитора.

## Плагин эффекта

```
src/effects/<id>/
  manifest.json   // id, name, version, settings[] (slider | range | color | toggle | select)
  index.ts        // export default class implements Effect
```

`build.mjs` сканирует `src/effects/*` и генерирует реестр — правок в ядре не требуется.
Интерфейс `Effect` — в `src/shared/types.ts` (init / update / render /
onSettingsChange / serialize / restore / destroy).

## Запуск

```bash
npm install          # первый раз
npm start            # dev-запуск (electron .)
bash scripts/make-app.sh   # собрать «Снег.app» + ярлык на рабочем столе
```

Приложение живёт в строке меню (❄). Клик по иконке → эффект, пауза, настройки.
Выход — из меню трея.
